# Keyboard shortcuts

`Ctrl` is `Cmd` on a Mac.

## Anywhere

| Keys                       | Does                                   |
| -------------------------- | -------------------------------------- |
| `Ctrl+Z`                   | Undo                                   |
| `Ctrl+Shift+Z` or `Ctrl+Y` | Redo                                   |
| `Ctrl+S`                   | Download the project as a `.bsig` file |
| `Ctrl+O`                   | Open a project or an exported figure   |
| `?`                        | Open this guide (outside a text field) |

## In a table

| Keys                           | Does                                     |
| ------------------------------ | ---------------------------------------- |
| Arrows                         | Move; with `Shift`, extend the selection |
| `Ctrl` + arrows                | Jump to the edge of the data             |
| `Tab` / `Shift+Tab`            | Move right / left                        |
| `Enter` / `Shift+Enter`        | Move down / up, keeping what you typed   |
| `Home` / `End`                 | Start / end of the row                   |
| `Ctrl+Home` / `Ctrl+End`       | First cell / last filled cell            |
| `Page Up` / `Page Down`        | A screen up / down                       |
| Typing                         | Replace the cell                         |
| `F2` or double-click           | Edit the cell, keeping its value         |
| `Escape`                       | Cancel the edit                          |
| `Delete` / `Backspace`         | Clear the selection                      |
| `Ctrl+A`                       | Select all the data                      |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copy, cut, paste                         |
| `Ctrl+D`                       | Fill down                                |
| `Ctrl+E`                       | Exclude or include the selected values   |
| `Ctrl+Shift+=` / `Ctrl+-`      | Insert / delete rows                     |

## On a graph

| Keys      | Does                                           |
| --------- | ---------------------------------------------- |
| `Escape`  | Back to the graph's settings                   |
| `↑` / `↓` | Move the selected bracket 1 pt (`Shift`: 5 pt) |

## In the navigator

| Keys                 | Does   |
| -------------------- | ------ |
| `F2` or double-click | Rename |
