# Exporting figures

**Export…** on a graph saves it as a file.

- **SVG** is vector graphics: it stays sharp at any size, journals accept
  it, and Illustrator and Inkscape open it with the text still editable.
  The font is named Arial, whose measurements the graph was laid out
  with, so it looks the same where Arial is installed.
- **PNG** is an image for slides and documents, at **300 DPI** or **600
  DPI (line art)**. The dialog shows its size in pixels.

## Size

**Size at print** offers journal column widths: **Single column (89 mm)**,
**1.5 columns (120 mm)** and **Double column (183 mm)**; the graph's own
size is under **Size (mm)** in its settings. Text and lines keep their
point sizes at any width (tick labels 7 pt, axis titles 8 pt), so a figure
exported at its final size needs no scaling — which is what journals ask
for.

## Reopening a figure

With **Include the data so this figure can be reopened** (the default),
the exported file carries its _recipe_: the graph, its data, its analyses
and their results, and the exact look. Open the SVG or PNG in BarelySig
(**Open…**, or drop it on the window) and you get the figure back, as a
new project, ready to change. Turn it off for unpublished data: the file
then only says that it was made with BarelySig.

If the figure is reopened by a newer version of BarelySig, its numbers
are recomputed and the graph says whether every number came out the same,
or which changed.

Every file, with data or not, says in its details (never on the image)
that it was made with BarelySig and which version.

## Export history

The graph lists every export under **Exported**, with its file name, date
and size. **Restore this figure** opens it exactly as it was exported, as a
new project, even if you have changed the data since.
