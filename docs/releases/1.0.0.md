# BarelySig 1.0.0

The first public release: statistics and graphs for bench experiments, in
the browser, with nothing to install and no data leaving your computer.

## Tables and data entry

- Column and Grouped tables, as Prism lays them out, with raw replicates or
  summary data (mean with SD, SEM or %CV, and n; or a mean with limits, for
  graphs).
- A data grid with Excel's keys; paste from Excel, Google Sheets and
  LibreOffice (headers, decimal commas, `#N/A` and friends handled and
  reported); exclude values without deleting them; undo everything.
- Projects are kept in the browser as you work; download and open `.bsig`
  files.

## Statistics (R, running in the browser)

- Descriptive statistics; unpaired, Welch's and paired t tests, also from
  summary data; Mann-Whitney and Wilcoxon tests with exact P even with
  ties.
- One-way ANOVA (and Welch's and Brown-Forsythe) with Tukey, Dunnett,
  Šidák, Bonferroni, Games-Howell, Dunnett T3 and Tamhane T2 comparisons;
  Kruskal-Wallis with Dunn's test, exact P for small samples; two-way
  ANOVA (Type III) with comparisons within rows, within columns or among
  all cells; D'Agostino-Pearson and Shapiro-Wilk normality tests.
- "Help me choose" suggests a test from a few questions about the
  experiment. Every result has a plain-language reading, P values as Prism
  formats them, and every analysis is validated against desktop R.

## Graphs

- Bars, dot plots (beeswarm), box-and-whisker and violin plots, grouped
  bars (interleaved or separated), with SD, SEM, 95% CI or range; a
  seaborn-style Modern theme and a Prism-like Classic one.
- Significance brackets from every pairwise analysis, stacked without
  overlap, draggable.
- Click any part of a graph to format it: axes (range, log scale, ticks),
  labels, colours, symbols, sizes, line widths.
- SVG and PNG export at a journal's column width, with the figure's recipe
  embedded so it can be reopened exactly; an export history per graph.

## Also

- A user guide in the app, from getting started to reading each test.
- Installable, works offline after the first visit.
- Anonymous, cookieless counts of which features are used; never data.
